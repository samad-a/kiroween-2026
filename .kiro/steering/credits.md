# Club Kiro: Credits

Budget is 4,000 Kiro credits, with unlimited time. Credits are scarce, so spend them carefully.

## Rules
- Be concise. Short answers, no recaps of what was just done.
- Only touch files the task needs. No drive-by edits or reformatting.
- Ask before big refactors, renames across many files, or dependency changes.
- Work in small, testable pieces, one task at a time.
- Read the relevant spec before writing code. Don't guess; ask if the spec is unclear.
- Don't add features, abstractions or tests beyond what the task asks for.
- Don't re-read files or re-run long commands without a reason.
- Don't start the CLI GitHub Action or Kiro Crew runs unless asked. They spend credits too.

## Leave to the human
Pixel nudges, colour changes and copy edits are cheaper done by hand.

## Commits
Commit at sensible points without asking first, so a bad change is a revert, not a re-prompt. Keep a coherent history: group a finished, coherent unit of work (often a few related tasks) into one commit rather than many tiny ones. Write clear messages. Never force-push, reset --hard, or rewrite pushed history without asking.

## Budget by phase
0 Setup 300, 1 Plaza 900, 2 Chat + Caretaker 900, 3 Mini-game, shop, rooms, UI 1,100, 4 Deploy 200, Reserve 600 (15%). Flag it if a task looks likely to blow its phase budget.
