# Haunted UI and rooms: requirements

Phase 3. Cosy-spooky look, identity, and personal rooms. See `.kiro/steering/product.md`.

1. The UI SHALL use a deep purple night, soft glow and flickering CSS lanterns. Panels SHALL look like parchment or tombstones.
2. Text SHALL meet readable contrast. Menus SHALL be keyboard-focusable.
3. The UI SHALL offer a reduced-motion setting and a mute button for sound.
4. WHEN a player first visits, a guest ID SHALL be created and kept in the browser.
5. The server SHALL issue a short recovery code. The same code SHALL always restore the same player.
6. Every player SHALL have a personal haunted room they can decorate by placing, moving and removing items.
7. The room layout SHALL be saved server-side.
8. Other players SHALL be able to visit a room from the plaza. ONLY the owner SHALL be able to edit it.
9. The Caretaker SHALL announce a "midnight haunting" event every N minutes, and the plaza lighting SHALL change.
10. Join and leave SHALL have visual effects.
